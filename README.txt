Everquinn: putting it on GitHub Pages

1. Create a new public repository (for example "everquinn").
2. Upload everything in this folder: index.html, manifest.webmanifest, sw.js and the icons folder.
   Keep the icons folder as it is. index.html must stay in the top level of the repository.
3. In the repository: Settings, Pages, "Deploy from a branch", branch main, folder /(root), Save.
4. After a minute the site is live at https://YOUR-NAME.github.io/everquinn/
5. On the iPhone, open that address in Safari, tap Share, then "Add to Home Screen".

Updating later: replace index.html in the repository. The app picks up the new version the
second time it is opened. Your books and settings stay on the device.
